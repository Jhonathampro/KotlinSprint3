## 📌 Sobre o projeto

O **Euro Tech** é uma aplicação Android desenvolvida em Kotlin com o objetivo de auxiliar gestores no acompanhamento da assiduidade dos alunos.

A plataforma permite visualizar informações por meio de um **dashboard**, consultar turmas e alunos cadastrados e realizar o cadastro de novos alunos e novas turmas.

---

## 🎯 Objetivo

O Euro Tech tem como objetivo facilitar o gerenciamento e acompanhamento dos alunos, permitindo ao gestor:

* Acompanhar a assiduidade dos alunos;
* Visualizar indicadores por meio de um dashboard;
* Consultar turmas cadastradas;
* Visualizar os alunos de cada turma;
* Cadastrar novos alunos;
* Cadastrar novas turmas.

# ⚙️ Instruções para executar

### 1. Pré-requisitos

É necessário possuir instalado:

* **Android Studio**
* **JDK** compatível com a versão utilizada pelo projeto
* Um **emulador Android** configurado ou um dispositivo Android físico com a depuração USB habilitada.

### 2. Executando o projeto

Abra o projeto no **Android Studio**, aguarde a sincronização do Gradle e execute o aplicativo em um emulador ou dispositivo físico utilizando o botão **Run ▶**.
